studio 의 **Curate** 페이지(`http://localhost:8730/curate`)에서 [시연 수집](../collect/)으로 모은 시연을 LeRobot dataset 으로 변환합니다. 변환할 때 시연마다 그리퍼 영상에 로봇 팔과 pegboard 를 그려 넣습니다.

## 단계

페이지는 위에서 아래로 두 단계입니다.

1. **Robot drawn**: 판정을 통과한 시연의 프레임 하나에 로봇을 그려 넣은 모습을 봅니다. 변환할 때 그리는 것과 같은 그림입니다.
2. **Convert**: 판정을 통과한 시연을 LeRobot dataset 으로 변환합니다. 시연마다 모든 프레임에 로봇을 그려 넣습니다.

## 로봇을 그려 넣는 이유

policy 가 보는 것은 두 그리퍼 카메라의 영상뿐입니다. 시연을 녹화할 때 그 영상에는 Hermit 을 든 사람의 팔과 방이 찍히지만, policy 를 실행할 때 같은 카메라에는 로봇 팔과 그 팔이 달린 pegboard 가 찍힙니다. 두 영상이 이렇게 달라서, 시연만 보고 배운 policy 는 실행할 때 처음 보는 그림을 받게 됩니다. 그래서 시연 영상마다 로봇이 서 있을 자리에 로봇을 그려 넣어, 학습하는 그림을 실행할 때의 그림에 가깝게 맞춥니다.

## 그려 넣는 방식

| 항목 | 방식 |
|---|---|
| 팔의 자리 | 시연자의 가슴을 로봇 보드의 자리로 보고([테이블 마커의 쓰임](../../deep/teleoperation/#테이블-마커의-쓰임)) 탑 카메라가 잰 손의 자리를 로봇의 world 에 옮깁니다. 첫 프레임은 ready 자세에서 IK 로 풀고 그다음은 앞 프레임에서 이어 따라가므로, Collect 페이지의 replay 가 팔을 놓는 방식과 같습니다 |
| 그리는 것 | 두 팔의 손목 아래 링크 전부와 베이스, 그리고 scene 의 pegboard 와 그 구멍. 그리퍼(claw, jaw, 서보, 카메라 브래킷)는 녹화된 Hermit 을 그대로 둡니다 |
| 카메라 | 그 순간 손이 들고 있던 그리퍼 카메라의 자리에서, 시연이 기록한 Kannala-Brandt 렌즈로 그립니다. 200° fisheye 라서 렌즈 평면 뒤쪽까지 보이고, 렌즈 원 바깥에는 그리지 않습니다 |
| 색 | 출력 부품은 같은 프레임에 보이는 다른 손의 Hermit 의 분홍을 재서 그 색으로 칠하므로 방의 조명을 따라갑니다. 다른 Hermit 이 안 보이는 프레임과 서보, pegboard 는 UMI 설정의 `robot_drawn_*` 색을 씁니다 |
| 가림 | 그린 부분은 그 자리에 찍힌 것(사람의 팔, Hermit 의 마커, 방) 위에 덮입니다. 두 그리퍼만은 덮지 않습니다 |

로봇을 그릴 수 없는 시연은 변환에서 빠지고, 진행 줄에 이유가 나옵니다.

- 두 손 시연이 아닐 때
- 테이블 마커를 가슴 앞에 두는 방식 이전에 녹화해 로봇의 world 에 옮길 수 없을 때
- 한 손이 처음부터 끝까지 한 번도 잡히지 않았을 때

교정이 담긴 [실행 기록](../../deep/corrections/)의 그리퍼 영상은 로봇의 카메라라서 로봇이 이미 찍혀 있으므로 그리지 않습니다.

## 미리보기

**Robot drawn** 에서 시연과 Left·Right 카메라, 프레임을 골라 그 프레임에 로봇을 그려 넣은 모습을 봅니다. 시연을 처음 고르면 그 시연 전체에서 팔을 따라가느라 몇 초 걸리고, 같은 시연의 다른 프레임은 바로 나옵니다.

## 변환

**Convert** 단계에 dataset 이름과 작업 설명을 적고 **Convert** 를 누르면 판정을 통과한 시연 전체를 변환합니다. 떨어진 시연은 지우지 않았어도 빠지고, 진행 줄에 빠진 이유가 나옵니다. 작업 설명은 시연한 작업을 **영어 문장**으로 적습니다(예: `pick and place the block`). dataset 은 `~/pinkrab/datasets/<이름>/` 에 저장되고 Datasets 목록에 나타납니다.

변환 설정은 따로 고르지 않습니다.

- **로봇**: 모든 시연에 그려 넣습니다. 시연 하나에 1 분 안팎이 걸립니다.
- **fps**: core 설정의 `dataset_fps`(50)이고, 학습한 policy 는 **이 주기로 실행됩니다**. 카메라 프레임 사이를 채우는 방법은 [dataset 의 fps](../../deep/convert/#dataset-의-fps) 에 있습니다.

변환이 끝나면 진행 줄 아래의 **View the dataset**, 또는 Datasets 목록 줄의 **View** 로 만든 dataset 을 엽니다. 왼쪽에 episode 와 그 episode 가 나온 시연이 나열되고, 두 그리퍼 영상을 dataset 에 저장된 그대로 재생합니다. 학습이 읽는 그림이 이것입니다.

같은 변환을 명령으로도 할 수 있습니다. 명령은 판정 없이 적은 시연을 그대로 변환하고, `--robot-drawn` 을 붙이면 로봇을 그려 넣습니다.

```bash
pinkrab-umi convert --robot-drawn --out pick_place --task "pick and place the block" <episode> <episode> ...
```
